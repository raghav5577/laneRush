# AGENTS.md — LaneRush: AI-Driven Adaptive Traffic Signal Control with EV Green Corridor

Instructions for coding agents (Codex, Claude Code, Cursor, etc.) implementing this repository.
Read this file fully before editing anything. Companion docs: `HLD_Adaptive_Traffic_Signal_Control.pdf` (what/why),
`Implementation_Architecture_Plan.pdf` (how/why-this-tech). If this file and the PDFs disagree, **ask the human**; do not guess.

## 1. Project in one paragraph

A simulation-only system on **SUMO + TraCI (Python)**. Each simulated second a controller reads lane state, scores each green
phase (`count + halting + aging*max_wait`), switches phases under min-green/max-green/hysteresis/yellow rules, and — when an
emergency vehicle (EV) is detected — pre-clears green phases at the next ≤3 signalised junctions on its route. Perception is behind a
`DetectionProvider` interface (ground truth / noisy emulator / YOLO). Results are judged by KPIs from SUMO `tripinfo.xml`.

## 2. Hard rules (never violate)

1. **Layering:** `src/lanerush/control/` MUST NOT import `traci`, `libsumo`, `redis`, `psycopg`, `sqlalchemy`, `ultralytics`, or anything from `perception/` implementations, `store/`, or `sim/`. It sees only `models.py` dataclasses. A test enforces this.
2. **Only `sim/traci_client.py` imports `traci`/`libsumo`.** Everything else uses its dataclass-returning methods or `FakeSim`.
3. **Safety invariants:** (a) only phases that exist in the SUMO program are ever selected; (b) every green→green change passes through yellow; (c) corridor override ignores min/max green only on junctions with an active request; (d) no green phase lasts longer than `max_green + 1` s except under an active corridor request.
4. **Graceful degradation:** Redis or Postgres failure → log one WARNING, fall back to `MemoryStore`/CSV, keep simulating. Never crash the sim loop because of storage or dashboard code.
5. **No magic constants** in logic code. Parameters come from the validated pydantic config (`config.py`).
6. **Reproducibility:** every run writes `runs/<ts>_<mode>_<seed>/{config.yaml,meta.json,tripinfo.xml,trips.csv,decisions.csv}`. `meta.json` has git hash, SUMO version, seed. Same config + seed ⇒ identical `tripinfo.xml`.
7. **Seed discipline:** tuning (fixed-timer scan, weight sweeps) uses seeds **101–105 only**. Reported results use seeds **1–10**. Never tune on test seeds.
8. **Do not edit** `models.py` or any `Protocol` without an explicit instruction; interface changes need human approval.
9. **Never commit:** `.env`, `*.pt` weights, `runs/`, `.venv/`, generated `net.net.xml`/`routes.rou.xml` (regenerated by scripts).
10. **No invented numbers.** Never hard-code or fabricate KPI results. Reports pull numbers from `runs/` via `evaluation/`.
11. **Honest reporting:** a goal is "achieved" only if the measured 95% CI lies on the right side of the target.

## 5. Contracts (authoritative signatures)

```python
@dataclass(frozen=True) class LaneObservation: lane_id:str; count:int; halting:int; max_wait:float; emergency:bool; source:str
@dataclass(frozen=True) class EVState: vehicle_id:str; edge:str; lane_id:str; lane_pos:float; lane_len:float; speed:float; route:tuple[str,...]; route_index:int
@dataclass(frozen=True) class TlsInfo: tls_id:str; green_phases:tuple[int,...]; yellow_after:dict[int,int]; lanes_of:dict[int,tuple[str,...]]
@dataclass(frozen=True) class CorridorRequest: tls_id:str; phase:int; eta_s:float; vehicle_id:str
@dataclass(frozen=True) class PhaseCommand: tls_id:str; action:Literal["hold","switch"]; target_phase:int|None; reason:str

class DetectionProvider(Protocol): def observe(self, t:int) -> dict[str, LaneObservation]
class StateStore(Protocol): put_tls, put_lane, put_ev(ttl_s=30), publish(channel, event)
class RunLogger(Protocol): decision(t, cmd, scores), lane_sample(t, obs), close()
```

Pure-function cores (unit-testable, no I/O): `lane_score`, `phase_scores`, `decide`, `plan` (corridor), `arbitrate`, `discover` (TLS structure), KPI functions.

## 6. Algorithms (spec)

- `lane_score = W_COUNT*count + W_HALT*halting + W_AGE*max_wait`, weights default `(1.0, 1.0, 0.5)`; `phase_score` = sum over lanes the phase turns green. `adaptive_noaging` ⇒ `W_AGE = 0`.
- `decide(in_yellow, t_in, cur_score, other_score)`:
  yellow → hold (`yellow_wait`); `t_in >= max_green and other>0` → switch (`maxgreen`); `t_in < min_green` → hold (`min_green`); `other > 1.2*cur + 1` → switch (`hysteresis`); else hold (`stay`). Defaults: min 8 s, max 50 s, yellow 3 s.
- Apply: switch ⇒ `setPhase(yellow_after[cur])` + `setPhaseDuration(yellow)`; hold ⇒ `setPhaseDuration(5)` each step.
- `discover`: green = state has `G/g` and no `y/Y`; yellow = has `y/Y`; each green must be followed (cyclic) by a yellow else raise a clear error naming the junction. v1 requires exactly 2 greens per junction; fail fast otherwise.
- Corridor `plan`: for each detected EV on a normal edge (not starting with `:`), look at ≤3 next signalised junctions on its route; `eta = dist / min(speed_limit, ev_vmax or v_free)`; request if `eta <= 12 + 2*halted_on_approach_lane`; the phase is the green serving `(incoming lane → next edge)`; use the lane that actually connects to the next edge (do **not** assume lane `_0`); if two EVs want the same junction the earliest ETA wins; requests vanish once the EV has passed.
- `arbitrate`: yellow → hold; request with different phase and `t_in >= 2` → switch (`corridor`); request with same phase → hold (`corridor_hold`); no request → pass the adaptive command through.
- Fairness: Jain `J = (Σm_i)² / (n·Σm_i²)` over per-entry-approach mean waits.
- Statistics: paired by seed; Wilcoxon signed-rank + paired t-test; 95% CI (t or bootstrap); ≥10 seeds (Wilcoxon with n=5 cannot reach p<0.05).

## 7. Modes

`fixed` (42/3/42/3) · `fixed_tuned` (best split from scan on seeds 101–105) · `adaptive_noaging` · `adaptive` · `adaptive_corridor`.
Later: `max_pressure`, `actuated` baselines; noisy-detector variants via `perception.provider: noisy`.

## 10. Known pitfalls (from the prototype — do not repeat)

- Hard-coded `SUMO_HOME`; assuming `yellow = green+1` or exactly two greens; using only lane `_0`; one constant free-flow speed for ETA.
- Tuning the fixed baseline on a test seed; marking a goal achieved below its target; 5 seeds with Wilcoxon.
- Silent `t < 3000` cap hiding gridlock; inconsistent EV identification (`type == "emergency"` vs `startswith("EV")`) — use one helper `is_emergency(vtype)`.
- `traci.vehicle.getWaitingTime` is the current *consecutive* standing time (verify for the installed SUMO); tripinfo `waitingTime` is cumulative. Use each for the right purpose (aging vs KPI).
- Tripinfo has no entry approach; take it from `trips.csv` recorded at departure.
- Parallel sweeps need a unique TraCI port per worker and guaranteed `traci.close()`.
